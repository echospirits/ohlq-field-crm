# Navigation

Historical implementation description below. Current release scope controls feature availability; Communications and Recipes are retired. The revised [UI/UX Guidelines](../UI-UX-GUIDELINES.md) govern new navigation and information-visibility decisions. Preserve canonical destinations, permissions, deep links and return context while allowing the arrangement and presentation to improve. Described expansion areas are not mandatory design patterns.

Preserve My Schedule, Accounts, Pipeline, Worklist, Log Visit, existing Opportunities/Agency Intelligence and Analytics. Communications remains in settings. Recipes adds a catalog because no equivalent management UI existed. Events and route ordering are disclosed inside My Schedule; event details link back to account and canonical Log Visit. Playbooks appear inside account Worklist. Profile, documents, account plan and reviewed assistant are expandable account sections.

`/deals` redirects to Pipeline and `/activities` redirects to the contextual account timeline or Log Visit. They are compatibility paths, not navigation destinations. The established UI guidelines remain mandatory at mobile and desktop sizes.
