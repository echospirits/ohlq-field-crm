Owner-authorized scope, November 3, 2026: extend Production Forecasting with cumulative 60- and 90-day horizons in the existing view, explain confidence/historical evaluation, and exclude the approved exact source line while preserving history. The initial TST-only work is complete. The owner subsequently instructed "push this to main," authorizing the selective production release described here.

Released to TST and production on November 3, 2026. The exact production application candidate `c5dcf07b8cc775488a3be9b69766e748bad3fb6f` is verified and tagged `v0.6.0`; stable TST application candidate is `d2f5c32d5badc5688c2a05ee54b50804ff3b1800`. Development remains frozen with no new cycle.

## Scope

- One horizon selector; retain mobile and desktop density, live search, filters, organization and return context.
- A coherent daily forecast path, model selection using pooled horizon errors, and separate horizon backtests, uncertainty ranges, prior-year demand, planning targets and eventual actuals.
- Retain original predictions and missing-data semantics; additive JSON only, no schema migration.
- Historical predicted-versus-actual evidence and a read-only audit; explain zero-demand metric limitations and the weakest-location product confidence rule.
- Owner-authorized exact source-line exclusion, with retained invoice evidence and removal of only its proven derived empty grouping. See [validation](production-invoice-exclusion-validation.md).

## Exclusions

No confidence threshold relaxation, new statistical candidate, AI model, inventory netting, ERP workflow, provider/scheduler change, dependency upgrade, migration or unrelated TST maintenance. Production receives only the requested forecasting paths, retaining main's existing test coverage and tooling.
