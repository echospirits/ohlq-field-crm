# Neat 0.4.1

Performance hotfix released October 28, 2026.

## Improved

- Account pages start independent reads together and show loading feedback for secondary account sections.
- Identity-only authentication and configuration reads avoid an unnecessary account-directory lookup. State restrictions remain in force for account data.

The reported production slowdown has not yet been measured against a baseline, and scoped account reads still load the state directory. No migration, feature flag, provider, or hosted-configuration change is included. The separate 0.5.0 field-workspace work remains in TST. [Validation](0.4.1-validation.md).
