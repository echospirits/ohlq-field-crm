# Neat 0.15.6 — Retail Inventory restriction labels

## Fixed

- Dead Inventory and other Retail Intelligence recommendations show **Restricted** when OHLQ marks a store and product pair as restricted. A regular zero minimum still appears as **Min 0**. The on-hand quantity appears alongside either label.
- The retail account’s Product opportunities and Current Inventory views show the same distinction.

## Release scope

This production patch applies the display and regression-test changes from TST `ad45a6e62ccabf8521e9305a74138400a82ddc12` to production base `25caec795ff838a7f3338fcc8b0890521ed87351`. Both recommendation views use the stored OHLQ coverage group from the existing inventory snapshot. The release requires no migration, backfill, dependency update, or configuration change.
