# 0.13.1

Released: 2026-09-30. Production version: `0.13.1`. Release tag: `v0.13.1`.

## Fixed

- Recent item sales on retail account pages now use the active organization's product list and labels, including when a platform administrator views that organization in Support View.
- Recent wholesale purchases now show only the active organization's tracked products. The account-wide list of other vendors' items is no longer displayed.
