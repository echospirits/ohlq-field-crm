# 0.13.2

Release date: 2026-09-30. Production version: `0.13.2`. Release tag: `v0.13.2`.

## Fixed

- Wholesale account pages again show two recent purchase sections: the active tenant's products over 30 days, followed by an expandable list of all OHLQ wholesale purchases at that account over the same period. This applies to regular tenant sessions and Support View.

## Internal release information

- Production base: `v0.13.1` plus its documentation-only release record (`828e66e8`). This hotfix restores the prior two-list wholesale presentation while retaining the explicit organization configuration introduced in 0.13.1. The retail tenant filter is unchanged.
- The all-purchases list is matched to the account's linked permit numbers and 30-day report window. The first list then selects only products configured for the active organization from those same matched rows. Each list summarizes all matches and displays up to 50 items.
- No migrations, data repair, environment changes, feature flag changes, or database mutations are required.
