# Neat 0.5.1 — Account address links

Owner-authorized hotfix, November 2, 2026. Development remains frozen.

## Fixed

Clicking a retail or wholesale account address opens that address in Google Maps location search so the user can review the location and choose whether to get directions. Account details and directory address links share this behavior on desktop and mobile. Explicit Directions buttons continue to open directions.
