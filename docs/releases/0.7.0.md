# Neat 0.7.0 - Echo-informed working interface

Stable **0.7.0** is deployed to TST and production following the owner's November 4, 2026 approval of the redesigned TST interface and request to push it to main. Production application `5023578de6bfda370ea547af7b1cb5494bbdfe70` and stable TST `214e0fe0cfb7d3184416408ea400ab0a023f7951` are READY with the correct environment/database health. Development remains frozen; no new cycle is opened. Authenticated production mobile/desktop acceptance passed, and annotated `v0.7.0` peels to the exact production application. The [completed checklist](0.7.0-checklist.md) and [validation record](0.7.0-validation.md) preserve the release receipts and acceptance limits.

## New

- Echo-informed working interface with Copper actions, Patina selections, Chalkboard navigation and clear neutral surfaces in light and dark appearances.
- More direct comparison through Pipeline, forecast, intelligence and Visit History tables, with useful account fields and next commitments visible beside each record.

## Improved

- Account overview shows saved profile and plan facts without opening an editor. Worklist exposes task context, due state and actionable failures near available actions.
- Mobile field work keeps account identity, visit context, contacts, directions and follow-up actions accessible. Desktop layouts use their width for comparison.
- Schedule shows events and overdue work; Tags and Users lead with existing records. Analytics and Data Status place useful summaries and source health before setup controls.
- Shorter labels, less routine explanatory text, compact toolbars and clearer navigation reduce visual overhead. Necessary source limits and warnings remain visible.

## Fixed

- Pipeline displays the earliest open commitment, including overdue or undated tasks; attention calculations keep their prior future-only semantics.
- Unknown purchase history reads `No recorded purchase`. Paused calendar synchronization is a neutral state, while actual failures remain actionable alerts.
- History Clear filters resets every record picker and both date fields consistently. Responsive reflow and mobile targets retain usable controls in affected views.
