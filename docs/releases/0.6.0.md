# Neat 0.6.0 — Production Forecasting horizons

Released to TST and production on November 3, 2026. The owner-authorized selective promotion, production exclusion activation and live forecasting smoke checks are complete. Exact application commit `c5dcf07b8cc775488a3be9b69766e748bad3fb6f` is tagged `v0.6.0`. See [validation](0.6.0-validation.md) and the [completed checklist](0.6.0-checklist.md). Development remains frozen; no new cycle is opened.

## New

- Choose cumulative **Next 30 / 60 / 90 days** in the existing Production Forecasting view. The same product table and detail update together, retaining search, filters, organization and return context.
- Inspect historical forecast-versus-actual checks inside the existing location disclosures. A read-only audit compares all three horizons with older outcomes and simple baselines.

## Improved

- One nonnegative daily forecast path produces consistent cumulative totals, with model selection using pooled historical error across the three horizons. Each horizon retains its own uncertainty range, prior-year comparison, confidence evidence and saved actuals.
- Longer-horizon detail uses two or three compact 30-day segments. Confidence help explains the evidence rating, sparse and zero-demand limits, and historical checks without expanding the default view.
- Shared computation caches avoid repeated model work; horizon navigation reads precomputed summaries. Original predictions remain retained, and actuals settle only with complete source coverage.

## Fixed

- Honor an owner-approved exact invoice exclusion through a reasoned tenant-specific input policy. Remove only its proven derived empty direct-invoice planning grouping while retaining raw source records, revisions, old predictions and coverage needed to evaluate older forecasts. Future valid invoices to the same agency remain eligible.
- Queue longer-horizon actual evaluation only when due, preserving capacity for newer completed forecasts.
