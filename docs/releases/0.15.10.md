# Neat 0.15.10 — Faster Log Visit

## Improved

- In-person sales visits require a note and at least one outcome. Outcomes and Sales status are always visible, with **No change** selected by default.
- **Add photo proof** starts with one photo picker and adds another as each photo is selected. Each photo can have its own category and caption.
- The structured dictation option and the retail account's Voice note shortcut are removed.

## Release scope

This hotfix uses the existing visit records, sales statuses and photo storage. It requires no migrations, dependency updates or configuration changes.
