# 0.12.0 — Permanent Echo bottle-sales retention

Status: **owner-authorized release preparation; production verification pending**.

## New

Echo Spirits bottle-sales records are protected from age-based deletion in both existing daily sales datasets, creating a durable basis for future historical reporting.

## Improved

Other vendors retain the existing 30-day operational window. Daily and post-import logs identify the permanent Echo policy and the configured window for other vendors.

## Fixed

Invalid retention counts, impossible report dates and unrepresentable cutoffs fail before any cleanup mutation is constructed.
