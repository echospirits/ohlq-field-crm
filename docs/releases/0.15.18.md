# Neat 0.15.18 — Echo bottle-sales history

## Fixed

- Bottle-sales reporting accepts certified history from January 1, 2019, so older backfilled months are no longer hidden by the former January 2025 boundary.
- Current and prior YTD eligibility follow the expanded horizon while continuing to require complete daily evidence for the comparison periods.

## Release scope

This owner-authorized production hotfix starts from main `20a02259` (0.15.17). Additive migration `20261125160000_echo_item_sales_history_2019` replaces two existing views, changing exactly five date constants. Existing column contracts, security-barrier settings, reader privileges, signed quantities and fingerprint validation remain intact. No raw sales, receipts, provider jobs, retention settings, credentials or application UI are changed. The main-only backfill continues independently; no TST synchronization is included.

The original production Looker dashboard cutover and cache refresh are separate consumer actions. Keep the three exclusions `3150B`, `3750B`, `4359B`, the matched-YTD readiness guards and the latest-complete-month metrics. See [validation](0.15.18-validation.md) for exact release evidence and [the reporting contract](../engineering/echo-item-sales-reporting.md) for semantics.
