# Neat 0.15.12 — Echo sales account access

## Improved

- Echo Settings no longer has an **Account states** control. Echo salespeople can work with Retail and Restaurant accounts across states under their existing permissions.
- Restaurant creation and Log Visit accept any U.S. state or D.C. Ohio remains the default. Saved addresses and geographic search filters remain available.
- Sales Analytics lists markets from supported sources and Echo products, with unavailable sales coverage labeled explicitly.

## Release scope

This release brings the Echo change from TST `796d04143e9aed2d6e9e3415e1502d8779000086` onto production `32bba254154da6c88bcc7aec17ff3de14c240303`. It preserves the production Log Visit workflow, organization-scoped private records, and source coverage rules for Ohio reporting and scheduled restaurant research. The application works with the existing schema, dependencies, and hosted configuration.
