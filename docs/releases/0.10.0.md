# Neat 0.10.0 — Production Supplies

Owner-approved production release, November 12, 2026. This selectively integrates accepted TST application `7cff2fdc5606efe868a3aa2341a124187516a280` onto production base `e2a19c9b45c7bbcbccdbbbf061879a00a43b7718`. It excludes earlier TST Tasting Management and later concurrent Social Publishing.

## New

- Supplies shows one ordering/delivery status card for each Dx5-alerted material and location.
- Repeated usage alerts update the same replenishment cycle. Dismissal persists; reliably completed deliveries remove cards without inventory or receipt writes.
- Relevant read-only email evidence and supported parcel tracking update statuses automatically when their production connections are activated. Uncertain, partial, returned and simulated deliveries cannot falsely complete a cycle.

## Improved

- The Production menu groups **Supplies** and **Forecasting** on desktop and mobile, preserving existing routes and access.
- Supplies is a simple status page, with Dismiss as its sole operational action. Inventory forecasting and lead-time planning remain in Dx5; Ollie is a future input seam.

## Technical manifest

The release adds tenant-scoped normalized Supply models, team/permission separation, read-only Gmail OAuth and encrypted tokens, authenticated Dx5 provenance, bounded resumable evidence replay, provider-scoped tracking and gated scheduling. Raw identifiers, source times, manual historical decisions and tenant boundaries remain intact.

Apply only additive migration `20261112010000_production_supplies`, normalized-LF SHA-256 `22228bae276adc7f8ca839bdc20b354c45291799f1a824d049e845c54d2b2daf`, after a production-derived rehearsal. No unrelated migration ledger reconciliation, dependency upgrade, destructive schema change or private TST data transfer is included.

The tenant entitlement remains disabled by default. Code deployment does not authorize private mailbox access. Production needs its own approved callback/client configuration, stable encryption key, owner consent and independently gated scheduler. TST credentials/tokens are not production credentials. EasyPost live tracking still requires approved keys/fees; GFS delivery and freight need additional supported integrations.
