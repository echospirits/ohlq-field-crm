# Neat 0.15.1 — Supplies email freshness

## Improved

- Supplies checks recent replies on watched orders before processing older mail. The existing six-hour schedule continues to allow at most four automatic batches per day.
- The Supplies dashboard shows when email checks are stale and links to mailbox status.

## Fixed

- Authenticated supplier replies can match a uniquely identified order across connected Production mailboxes using stable message references.
- Confirmed payment clears a payment-only hold. The card shows **Awaiting shipment** until shipment is confirmed. A supplier promise to send a bill of lading is retained as a promise.

## Release scope

Selective Supplies hotfix from main `e352e3b7f8b4ad7a23938578b3bde09661a00f9b` (0.15.0) with the same Supplies code tested on TST. This changes the mailbox importer, lifecycle matching and display, focused tests, release notes and package version metadata. Existing consent, authorization, scheduled job configuration, shared database schema and dependency graph are preserved. TST keeps its existing version and paused Supplies worker.
