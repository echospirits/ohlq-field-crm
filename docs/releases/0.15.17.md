# Neat 0.15.17 — Supplies freight and recent email

## Improved

- Production schedules recent watched-order replies and freight notices every 15 minutes through GitHub Actions, with a daily Vercel backstop. Historical processing retains its six-hour cadence.
- An attached bill of lading can add freight details to the shipment already identified in the vendor’s message. The card reports **Bill of lading received** while carrier pickup remains unconfirmed.
- A tenant with approved Ward API access can look up Ward freight by the carrier’s PRO number or the bill of lading and origin ZIP.

## Fixed

- The production email check runs directly on the authenticated cron route and claims work in the database. A stalled legacy Workflow can no longer hold up new freight notices.
- Verified freight delivery can close the specifically reviewed replenishment even when the original stock alert omitted a location. Later alerts still open a new cycle.

## Release scope

This is a selective Supplies hotfix. TST automatic processing stays paused. The production route keeps its existing authentication, tenant entitlement, mailbox consent, and retry fences. No schema or dependency change is required. Ward API lookups start disabled until the tenant has approved credentials. The independent public carrier verification and audited correction do not create internal receipts or inventory changes.
