# Neat 0.15.16 — OHLQ links on wholesale purchases

## Improved

- Item codes in **Tracked products** and **All purchases** open OHLQ search results for the exact code in a new tab. Codes retain leading zeros and bottle-size suffixes.

## Release scope

The purchase card, styles and regression test match the three files tested on [TST](https://github.com/echospirits/neat-tst/commit/d24a8ae59076ffa5bba13b2c33239c0d1a2ff133). This release requires no migration, dependency change or hosted configuration change.
