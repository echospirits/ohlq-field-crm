## Direction contract

Neat is a field and comparison workspace. The first viewport should expose useful work, not a stack of explanations or unopened areas. Desktop supports cross-record comparison; mobile preserves the decisive facts and reachable actions. Existing data, canonical workflows and reliable behavior survive the redesign.

The approved direction adapts Echo's Copper, Patina and Chalkboard identity into a neutral, restrained working interface: precise alignment, readable sans-serif type, compact tables, fine dividers, modest radii, clear status and short local qualifiers. Interstate web rights/files are not assumed. Shared CSS uses an available system sans serif. No decorative raster asset is required.

This is a code-led application implementation of the owner-approved guideline direction. Impeccable's direction exercise was considered within that pinned brief; unrelated visual metaphors do not replace the approved identity. Review actual populated component renders and the authenticated application, rather than treating an illustrative comp as runtime evidence.

## Scope by workstream

1. Shared theme, shell, navigation and page chrome: apply semantic light/dark tokens, compact hierarchy and useful desktop width. Keep frequent Insights/Intelligence destinations directly available; administrative setup stays secondary.
2. Accounts, Worklist and Pipeline: task-driven directory columns; saved read summaries separate from editing; visible task context and actionable failures; comparison tables with existing filtering/context and alternate boards retained.
3. Intelligence: align account/product facts, stock, sales, fit and reasons. Keep decisive evidence visible, with full methods/history secondary.
4. Analytics and Forecasting: one responsive product comparison representation, visible horizon/filter/sort scope, compact delivery/current-demand summaries, aligned period/location/history views and material uncertainty.
5. Daily work and forms: visible events/overdue work, concise visit context/contact choices, browsing before creation in Tags/Users, compact global visit history, read-before-edit event detail, restrained order and calendar help.
6. Administration and remaining routes: source health and actionable failures before refresh/setup, comparison rosters, concise copy, safe configuration summaries, shared error/empty/loading/disabled/success treatment.

The [route audit](../design/neat-tst-ui-audit-2026-11-04.md) records inspected routes and outcomes. Compatibility redirects and retired destinations remain intact; no retired feature is restored.
