# Neat 0.15.11

## Improved

- Log Visit opens with recent suggestions or the account from the originating page. Contact choices load for the selected account. Account search responds as you type and lets you retry a failed lookup.
- Visit confirmation appears once the saved visit can be read. Related work is available from confirmation after it loads. Calendar sync for physical visit follow-ups runs after the response.
- My Schedule shows personal work and visit actions before team summaries. Recent Visits loads photo thumbnails when you open a gallery.

## Fixed

- A rapid second tap on Save cannot send a second form request from the same screen. The Sales visit submission key also protects persisted visits on retry, and the form retains entered values after a connection error.

## Internal manifest

Selective performance release from the TST audit. Existing production permissions, account scope, and reporting rules are preserved. No Prisma migration, new dependency, provider configuration or feature enrollment is required. The existing TST pilots remain independent. Sampled form, search, and save timings are described in the [validation record](field-performance-validation.md).
