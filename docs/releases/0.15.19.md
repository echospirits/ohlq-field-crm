# Neat 0.15.19 — Account address search

## Fixed

- Account Search, Retail, Restaurants, and account pickers for visits and scheduling match street address, city, county, state, ZIP, and combined address details such as a city with its ZIP.
- Account Search and the Retail directory show the ZIP in the results when the account has one.

This hotfix uses the existing address fields and account-access rules. It requires no migration, backfill, or configuration change.
