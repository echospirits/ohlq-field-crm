# Neat 0.15.7 — Account Research location matching

## Fixed

- Account Research can match a public street number within an Ohio liquor-permit address range or among its explicit street numbers.
- Verified Ohio city aliases match within the same ZIP. The validator checks the street and any required unit, and still requires evidence for the specific venue.
- Research instructions distinguish regular closed days from confirmed closures and ask for evidence tying the current operator or trade name to the location.

## Release scope

This hotfix applies the matching rules tested on TST at `e659a0987cd8375df21f5b480530116bf347e264` to production base `ea06b3aa0aa82cf65233d8f855c4369c83eccd82`. It requires no migrations, dependency updates, or configuration changes.
