# Neat 0.7.3 — Forecasting vendor bailment scope

Owner-authorized scoped correction, November 9, 2026, for `neat-tst/tst` and production/main. Development remains frozen outside this change. Unrelated TST tasting features, migrations and maintenance are excluded from main.

## Improved

Production Forecasting includes all A3A BAIL products associated with the organization's active Ohio vendor record, including sales-excluded item **3150B**. This selection applies to the dashboard, detail, forecasts, source imports and Current Demand. Sales-product decisions and sales/inventory reporting retain their existing exclusions.

## Technical manifest

- Retain exact vendor-linked bailment code/name evidence in completed inventory-import diagnostics before the existing sales filter; no additional shared inventory rows are imported. Active Ohio vendor IDs are resolved from organization records. An explicitly empty diagnostic catalog excludes stale listings; legacy diagnostics fall back to current exact-classification inventory evidence.
- Reuse product IDs for composite forecast/source relationships without promoting their sales status. Source import creates absent identities only as inactive EXCLUDED records with duplicate skipping; existing records are never updated by this step. Reads remain read-only.
- Preserve delisted status 30, discontinued identities, Distillery Only exclusions, entitlements, organization/state boundaries, append-only source reconciliation and immutable forecasts. Other markets retain their existing portfolio rule. Unknown coverage stays unavailable; trusted complete exports may establish zero coverage.
- No dependency upgrade, schema/migration, backfill SQL, hosted/provider configuration, credential, feature-flag or sales-filter change. Package/lock metadata advances from 0.7.2 to 0.7.3.
- Deployment must refresh inventory metadata before production sources/forecasts to discover excluded items. Reverting this correction requires no database rollback; retain diagnostics, excluded identities and historical observations.
