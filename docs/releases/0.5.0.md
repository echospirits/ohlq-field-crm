# Neat 0.5.0

Released October 29, 2026 (Eastern). Annotated tag `v0.5.0` identifies verified application commit `9a16bf99fe1a2ee8b3c415beb3097b56bb8eff26`. Development remains frozen.

## New

- Named account sections keep Notes, Contacts, outstanding work and a concise briefing easy to find, with account context and entered form values preserved.
- Mobile More includes Log visit, alongside the existing contextual account actions.

## Improved

- Schedule, account submenus and intelligence views use clearer text hierarchy, compact rows and dividers. Evidence and optional controls remain available when needed.
- Directory search comes before Nearby accounts. Nearby opens from a compact, initially closed disclosure with flat rows, retaining distance accuracy and known visit information.
- Retail and restaurant browsing use stable pages of 50 records; intelligence queues use 25. Search, sorting, continuation and return context remain intact.
- Pipeline opens on its account list, with search visible and optional scope filters tucked away. Worklist leads with account identity and relative urgency.
- Account loading avoids query waterfalls, and layout/page authentication shares a session read only within the same request and cookie.

## Fixed

- Repeated missing-history fields no longer overwhelm account briefings or directory summaries.
- Floating visit controls no longer obscure page content; mobile buttons and disclosures have a 44px touch floor.
- Worklist search finds tasks through linked account names, including legacy references.
- Sources and Import links reveal their Forecast sections. Existing source uncertainty remains visible.
