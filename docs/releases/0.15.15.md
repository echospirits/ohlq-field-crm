# Neat 0.15.15 — Wholesale purchase prices

## Improved

- Wholesale account purchases show the latest imported OHLQ wholesale price per bottle for each item code in Tracked products and All purchases. Items without a usable price show **Unavailable**. Catalog prices may differ from what the account paid.

## Release scope

The purchase card, data lookup and regression tests match the five files tested on [TST](https://github.com/echospirits/neat-tst/commit/d0dcf484a06c6fb34492e7b39f5ccb134775bf56). The price uses the existing OHLQ Brand Master lookup. This release requires no migration, dependency change or hosted configuration change.
