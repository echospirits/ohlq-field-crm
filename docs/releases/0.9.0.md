## New

- Admins and platform administrators can request a Production Forecasting refresh with one button. Relevant source reports are fetched in the background and forecasts are saved automatically.
- The page shows queued/running progress and the saved outcome, with clear partial/failure/timeout states and retry recovery.

## Improved

- Refresh keeps the current product search and forecast horizon in place. The normal manual source-upload section is replaced by the automatic control.
- Real report/retrieval dates remain visible. Existing current daily warehouse, demand and delivery observations retain their original provenance when reused.
- Duplicate clicks share one active organization request. Sales retains its existing read-only forecasting access.

## Fixed

- Missing refresh configuration disables the action with an explanation. A queued request alone never appears as a completed source refresh.
- Browser-provider code loads only in the background worker, keeping the foreground forecasting page and request/status actions compatible with the serverless deployment.

### Technical scope

- **Behavior:** an Admin/platform Admin refresh button replaces the normal upload section. The dedicated workflow downloads complete outbound case history and DC guidance, saves forecasts and fills missing daily operational observations through the existing canonical source workflow. Search and horizon remain in place.
- **Request state:** persist organization-scoped QUEUED/RUNNING/SUCCEEDED/PARTIAL/FAILED/TIMED_OUT history; coalesce duplicate clicks; recheck active administrator, organization and forecast entitlement before execution. Queue expiry is five hours; running work has a 15-minute lease, one-minute heartbeat and 90-minute absolute deadline. Claim/heartbeat/completion guards fence late or duplicate workers. Request lifecycle timestamps do not replace source freshness.
- **Existing data:** preserve actual source/report/retrieval dates and current immutable daily operational observations. No annual-sales or shared-inventory import, product-policy change, statistical-model change, credential repair or provider-account change. `3150B` remains active / EXCLUDED with zero current or historical shared-inventory rows.
