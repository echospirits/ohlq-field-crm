# 0.15.0 — Direct Echo bottle-sales reporting

Status: **owner-authorized production candidate; production migration, restricted-reader verification and the copied dashboard's main connection/empty-state checks pass. Application publication and populated-history acceptance are pending.**

## New

An Echo-only Neon reporting source supplies monthly bottle sales, product performance, agency performance and channel trends using the existing dashboard field names. A separate status source shows whether historical coverage is ready, partial or still pending.

## Improved

Monthly reporting keeps signed retail and wholesale quantities, original product/agency codes and current labels, including the verified Echo A3A locations. Source receipts must match the saved facts before a day counts as complete. Missing history cannot silently appear as zero, and matched-year comparisons advance only through contiguous certified closed months.

## Operating scope

The owner explicitly directed **main/production-only** backfill and reporting on November 21, 2026. Both reusable sources in the copied dashboard now connect to that same production database. No TST backfill or data synchronization is part of this release. Codex separately owns historical ingestion and the receipt writer for backfill, zero-sale days, corrections and future daily loads. The preview truthfully shows pending history; original production bottle pages retain their spreadsheet sources until complete evidence and reconciliation justify cutover.
